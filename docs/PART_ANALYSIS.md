# Part analysis

Open **Playback options → Part analysis** to compare the recording, detected
events and chart notes for an instrument. The drawer stays above the selection
desk and timeline, and remains open when you collapse Playback options. Scroll
inside the drawer to see later sections. Use its close button or Escape to return
to the note editor.

1. Choose the instrument and a section.
2. Listen to the original or matching stem.
3. Compare attacks and pitches with the chart.
4. Edit the notes, then replay the section.

Attack markers describe changes in the audio. They are useful timing prompts,
but do not prove which instrument played or that a chart needs another note.
Drum views can group activity by frequency band; a bright band is not a separate
physical drum.

Optional kit-component listening uses local LarsNet models. See
[Drum components](DRUM_PARTS.md) for setup and model terms.

For command-line analysis options:

```sh
chart-engine part-analysis --help
```
