# Drum articulation

Pro Drums uses cymbal markers on the colored drum lanes. Standard drums omit
those markers. Select a note and use **Cymbal** in the Inspector where supported.
Kick and snare cannot be cymbals.

Generated proposals can use the isolated drum stem and an optional OAF Drums
model to help distinguish ride and crash. Tom assignments and cymbal identities
still need listening review. A spectral peak alone does not identify a drum.

Listen around each fill and cymbal change. Check the selected lane and marker
in the note editor, then test the exported part in the target game.
