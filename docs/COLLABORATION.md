# Collaborate on a chart

Each person works in their own YACE review project. Share proposals and review
files through Git, a shared folder or a portable bundle. YACE accounts and a
hosted server are not required.

## Share review files

1. Open **Collaborate** in the toolbar and enter your name.
2. Export a review bundle, or sync with a shared review folder.
3. Ask the other person to import or sync those files in their project.

Audio is not included in review exchange. Collaborators need matching source
material. Check proposal text and discussions before sharing private information.
Names are local attribution, not verified accounts.

## Propose and merge

Enter a proposal title and description. Export changes against an unchanged
base project, then exchange the proposal. Review comments and suggested edits
remain attached to the proposal.

Merge only after the required approval. If notes conflict, choose the musical
result for each note. Saving conflict choices creates another proposal for
review. It does not overwrite the song or transfer earlier approval.

Keep project copies and use Undo to recover changes. Share review files rather
than text-merging `project.json`.

## Git

Expand **Share with Git** to create, clone or select a dedicated review repo.
Use **Save / Pull / Publish reviews** to synchronize it. Publishing uses your
existing Git credentials and happens only when you select that operation.

See [the exchange format](COLLABORATION_FORMAT.md) for integration details.
