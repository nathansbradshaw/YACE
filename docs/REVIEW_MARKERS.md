# Review markers

Review markers point to sections that may need attention. They can come from
generation checks or note-pattern checks. A flag is a prompt, not a verdict.

Select a marker to jump to its track and time range. The detail view shows the
reason and available measurements. Listen, edit and replay before deciding.

| Decision | Meaning |
| --- | --- |
| Pending | Still needs review. |
| Reviewed | Checked with the recorded information. |
| Resolved | The reviewer considers the issue addressed. |
| Dismissed | The reviewer accepts or rejects the flag with a reason. |

Nonpending decisions require a comment. Relevant note edits make older decisions
stale. Hiding a flag changes visibility without approving it. **Hidden flags**
reveals hidden markers so they can be restored.

Saved markers identify the chart and recording they belong to. Markers from a
different or changed source cannot be attached as if they were current.
Unflagged sections still need review.
