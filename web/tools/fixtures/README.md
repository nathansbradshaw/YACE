# Synthetic Vorbis headroom fixture

`headroom.ogg` contains two synthetic tones generated by `headroom.rs`: a loud
440 Hz left channel and quiet 880 Hz right channel. No recording is included.
The encoded stream contains 5120 stereo frames at 44100 Hz, including encoder
padding. Both the native and Rust decoders retain that stream clock.

Rebuild with Rust and FFmpeg's built-in experimental Vorbis encoder:

```sh
rustc --edition=2024 web/tools/fixtures/headroom.rs -o /tmp/yace-headroom
/tmp/yace-headroom /tmp/headroom.wav
ffmpeg -i /tmp/headroom.wav -c:a vorbis -strict -2 -map_metadata -1 \
  -metadata comment='Synthetic codec test tone; not a recording' \
  web/tools/fixtures/headroom.ogg
```

The regression checks decoded frame count, channel identity and float headroom.
