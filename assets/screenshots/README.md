# README screenshots

Screenshots of the macOS app.

`editor.png` shows a synthetic demo chart with a selected drum note.
`generation.png` shows the local-audio generation dialog before choosing a file.
The demo uses a short synthesized recording and small practice patterns; it
contains no private songs, lyrics, artwork or trained weights.

When updating the UI, recapture these views from the running app. Keep the
README captions and screenshots in sync. Do not capture private project data.
